Licensed Museo Sans webfonts go here (exljbris Font Foundry, www.exljbris.com).
Expected file names, referenced by /css/site.css @font-face rules:

  museo-sans-500.woff2   (Museo Sans 500)
  museo-sans-700.woff2   (Museo Sans 700)
  museo-sans-900.woff2   (Museo Sans 900)

Drop the files in with exactly these names. No other edit is needed: the CSS
font stacks list "Museo Sans" first and Figtree (Google Fonts) as the fallback,
and /js/site.js turns off the Figtree-only spacing tweaks (html.ff-figtree)
once a Museo Sans face has loaded. Check that the licence covers web embedding
for the domain www.legacyvpartners.com.
